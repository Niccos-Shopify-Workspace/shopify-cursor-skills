# Shopify Skills

Agent skills for Shopify theme development with best practices, coding standards, and guidelines.

## Install

```bash
npx skills add Niccos-Shopify-Workspace/shopify-cursor-skills
```

## Available Skills

### Theme Development Skills

| Skill | Description |
|-------|-------------|
| [shopify-section-structure](./.cursor/skills/shopify-section-structure/) | Section file structure, schema requirements, and padding settings |
| [shopify-css-guidelines](./.cursor/skills/shopify-css-guidelines/) | CSS naming conventions (BEM), nesting rules, and encapsulation |
| [shopify-liquid-templates](./.cursor/skills/shopify-liquid-templates/) | Liquid snippets, logic, image handling, and SVG usage |
| [shopify-javascript-standards](./.cursor/skills/shopify-javascript-standards/) | JavaScript file structure, custom elements, and coding standards |
| [shopify-html-data-comments](./.cursor/skills/shopify-html-data-comments/) | HTML structure, data attributes, and commenting guidelines |

## What These Skills Cover

These skills provide comprehensive guidelines for Shopify theme development:

- **Section Structure**: File organization, schema configuration, padding settings
- **CSS Standards**: BEM methodology, nesting rules, encapsulation
- **Liquid Templates**: Snippets, logic flow, image handling, SVG usage
- **JavaScript**: Custom elements, file structure, best practices
- **HTML & Data**: Semantic markup, data attributes, commenting

## Tech Stack

These skills are designed for Shopify theme development:

- **Templating**: [Liquid](https://shopify.dev/docs/api/liquid)
- **Styling**: Native CSS with modern features (nesting, custom properties)
- **JavaScript**: Vanilla JS with Custom Elements (Web Components)
- **Theme Architecture**: [Shopify Theme Structure](https://shopify.dev/docs/themes/architecture)
